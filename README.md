# Skill Gap Checker

A beginner-friendly Python project that compares a user's skills with the skills required for a job and identifies missing skills.

## Features

- Compare required job skills with personal skills
- Find matching skills
- Find missing skills
- Calculate skill match percentage
- Give learning recommendations

## Technologies Used

- Python
- Git
- GitHub

## How to Run

1. Clone the repository

2. Open the project folder

3. Run:

```bash
python app.py
